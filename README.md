# ESTMC
Official implementation of our TPAMI work:

**“Anchors Crash Tensor: Efficient and Scalable Tensorial Multi-view Subspace Clustering”**

**📄 [Paper with Appendix](./Manuscript%20with%20Appendix.pdf)**

# Dataset
We only provide several datasets (i.e., NGs, BBCSport, CCV, HW, BDGP_fea); you can download more datasets [here](https://github.com/wangsiwei2010/large_scale_multi-view_clustering_datasets).

**Please note that the commonly used datasets listed here are all pre-sorted by category; this is an implicit assumption underlying the excellent performance of the tensor method on some datasets.**
